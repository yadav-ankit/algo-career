You’ve hit one of the biggest conceptual confusions in DP:

In memoization, are we returning from recursion or returning from dp[]?

Answer:

Both, depending on the situation.

Let’s separate them.

Memoization (Top-down DP)

Example:

int solve(int idx)

We return:

return solve(0);

Inside:

if (dp[idx] != -1)
    return dp[idx];

...

return dp[idx] = answer;

Notice:

We return recursion result,
but cache it in dp.

dp[] is only storage.
